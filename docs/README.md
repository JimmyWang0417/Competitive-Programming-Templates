# 文档

本目录保存适合连续阅读的详细教程；`Templates/` 下的 Typst 内容则面向算法竞赛纸质模板，优先提供可以在赛场快速检索的结论、公式和算法步骤。

## 组合数学

- [杨表（Young Tableaux）详细教程](./math/young-tableaux.md)：从整数分拆、杨图和钩长公式讲到 RSK、Schensted 与 Greene 定理，包含证明、例题和练习。
- [杨表纸质速查版](../Templates/math/youngTableaux.typ)：竞赛常用性质、计数公式及行插入/逆插入流程。

## 图论

- [2-SAT：蕴含图、配对反边与强连通分量](./graph/two-sat.md)：重点解释为什么每条蕴含必须显式加入逆否边，并给出省略后的误判反例。
- [Dilworth 定理、Mirsky 定理与 DAG 覆盖](./graph/dilworth.md)：整理两个极值定理、二分图匹配算法及传递闭包边界。
